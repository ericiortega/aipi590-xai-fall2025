# 🧠 Mechanistic Interpretability — Explaining a Tiny Brain

This assignment explores the concept of **mechanistic interpretability** by analyzing the internal behavior of a small neural network trained on a simple task.  
The objective is to uncover how individual neurons or components represent meaningful features, connecting low-level computations to human-understandable logic.

## 📋 Case Details
- **Case Domain:** Mechanistic Interpretability & Neural Understanding  
- **Assigned Role:** Neuron Detective 🕵️‍♂️  
- **Goal:** Build and train a tiny neural network (e.g., XOR) and identify one interpretable neuron, attention head, or component that encodes a meaningful feature through activation and weight analysis.  
- **Deliverables:** Colab notebook with model code, visualizations, and written reflection.
