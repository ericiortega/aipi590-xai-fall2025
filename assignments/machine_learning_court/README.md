# ⚖️ Machine Learning Court – Recidivism Prediction (Defense)

This assignment investigates the use of explainable AI (XAI) techniques to analyze an AI model’s prediction in the context of **recidivism risk assessment** using the COMPAS dataset.  

## 📂 Case Details
- **Case Domain:** Recidivism Prediction  
- **Assigned Role:** Defense  
- **Goal:** Demonstrate the validity and fairness of the model’s predictions using at least two XAI methods.
