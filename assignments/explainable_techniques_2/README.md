# Explainable Techniques II

This assignment applies advanced explainability methods (PDP, ICE, ALE) to a chosen model and dataset.  
The goal is to analyze how features influence predictions and investigate the effect of feature correlations.  

---

## Assignment Tasks
1. **Produce Explainability Plots**
   - Generate Partial Dependence Plots (PDP)
   - Generate Individual Conditional Expectation (ICE) plots
   - Generate Accumulated Local Effects (ALE) plots

2. **Perform Exploratory Analysis**
   - Check correlations between features
   - Discuss how correlations may impact PDP vs ALE interpretations
   - Highlight interesting findings in model behavior
